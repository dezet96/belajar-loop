1 Apa itu Perulangan?

Konsep dasar sebelum masuk ke kode.

Perulangan (looping) adalah perintah untuk menjalankan blok kode berulang kali selama kondisi tertentu terpenuhi. Tanpa perulangan, kita harus menulis kode yang sama berulang-ulang — tidak efisien!

💡 Analogi: Saat kamu lari di lapangan, kamu menghitung "putaran 1, putaran 2, ..." sampai target 5 putaran. Itu adalah perulangan! Kondisi berhenti = "putaran ke-5 tercapai".

Tiga komponen wajib perulangan:

  • Nilai awal — dari mana perulangan mulai
  • Kondisi berhenti — kapan perulangan berhenti
  • Perubahan nilai — bagaimana nilai berubah tiap iterasi

C memiliki 3 jenis perulangan: for, while, dan do-while. Kita akan pelajari lewat praktik!

Kata Loopi

Kalau salah satu dari 3 komponen lupa, bisa jadi infinite loop — program berjalan terus tanpa henti! 😱

2 Studi Kasus 1 — Bilangan Genap

Pelajari contoh dulu, lalu kerjakan latihan.

📖 Contoh Kode — Perulangan for

Mencetak Angka 1 sampai 5

Perhatikan contoh sederhana berikut. Program mencetak angka 1 sampai 5 menggunakan for.

#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i++) {
        printf("%d ", i);
    }
    return 0;
}

Output: 1 2 3 4 5

Cara kerja: mulai dari i = 1, selama i <= 5, cetak i, lalu naikkan i dengan i++. Perulangan berhenti saat i bernilai 6.

🔢

4 Studi Kasus 2 — Menu Kantin

Pelajari contoh dulu, lalu kerjakan latihan.

📖 Contoh Kode — Perulangan do-while

Menu Sederhana 2 Pilihan

Perhatikan contoh menu sederhana berikut. Menu tampil, user memilih, dan berhenti saat pilih keluar (2).

#include <stdio.h>

int main() {
    int pilih;
    do {
        printf("1. Mulai\n2. Keluar\n");
        printf("Pilih: ");
        scanf("%d", &pilih);
    } while (pilih != 2);
    return 0;
}

Cara kerja: blok do dijalankan dulu (menu tampil), lalu cek kondisi while (pilih != 2). Selama user tidak memilih 2, menu diulang.

🍜

Latihan: Menu Kantin 3 Pilihan do-while

Masalah: Buat menu kantin yang selalu tampil minimal 1x. Menu: 1. Makan, 2. Minum, 3. Keluar. Program berulang sampai user pilih 3 (Keluar).

🎯 Kenapa do-while? Karena menu harus tampil dulu sebelum user bisa memilih.

📝 Rangkuman

  • for → jumlah iterasi pasti, cocok untuk hitungan
  • while → cek kondisi dulu, cocok untuk perulangan tak tentu
  • do-while → eksekusi minimal 1x, cocok untuk menu
  • Selalu pastikan ada perubahan nilai agar tidak infinite loop
  • Perhatikan batas kondisi (< vs <=)
